## [Unreleased] — Sprint 8 & Sprint 9 Security Hardening, Honest Architecture Classification & Release Readiness (2026-11-05)

- **Sprint 9 — Critical Authentication Bypass (`B1`) & RBAC/Tenant Hardening (`apps/api`, `apps/web`)**:
  - **`S9-01` (`B1` P0)**: Removed `X-Demo-Principal` authentication bypass completely across [`apps/api/public/index.php`](apps/api/public/index.php), [`apps/api/app/Http/Controllers/Api/V1/PlatformApiController.php`](apps/api/app/Http/Controllers/Api/V1/PlatformApiController.php), [`apps/web/src/server.ts`](apps/web/src/server.ts), and [`apps/web/src/lib/api-client.ts`](apps/web/src/lib/api-client.ts). Client-supplied headers can never determine identity in any environment.
  - **`S9-02` (`B1` P0)**: Separated demo seeding behind explicit [`RuntimeMode::demoModeEnabled()`](apps/api/app/Support/RuntimeMode.php) (`HEGOSENTINEL_DEMO_MODE=1`, hard-disabled when `APP_ENV=production`) and replaced personal demo names with neutral labels (`Demo Owner`, `Demo Security Lead`).
  - **`S9-03` (`B1` P0)**: Closed self-registration tenant takeover in `register()` (`organization_id`, `role`, and `allowed_project_ids` in `/api/v1/auth/register` payloads are ignored; registration always creates an isolated new organization).
  - **`S9-04`..`S9-11` (API Security Re-Audit)**: Required explicit initial password (`>=10` chars) and same-org `allowed_project_ids` validation on `/api/v1/team/members`; added login brute-force throttling (`auth_login_attempts` table, HTTP `429`); restricted Re-Test (`runRecheckComparison`) to `manage_remediation` roles and same-project scans; restricted `/api/v1/audit-logs` to `read_audit` (`owner`/`security_lead`) and scoped notifications/emergency-stops to assigned projects; blocked manual `verified_closed` task transitions (`422`); scrubbed foreign tenant/project IDs (`foreign_ref` hash) on cross-tenant denial logs; confined `repository_path` via [`RuntimeMode::resolveRepositoryPath()`](apps/api/app/Support/RuntimeMode.php) to registered project assets under `examples/`; and enforced project-wide emergency-stop cooldown (`HEGOSENTINEL_ESTOP_HOLD_SECONDS`, default `900s`) unconditionally.
  - **`S9-16` & `S9-17` (Web UI Server Hardening)**: Rejected `%2e%2e` path traversal on `/api/v1/` proxy requests (`400`), enforced a 1 MiB proxy request body limit (`413`), and hid demo quick-switch controls unless `HEGOSENTINEL_DEMO_MODE=1` outside production.
- **Sprint 9 — Trusted Egress Broker Hardening (`B2`, `apps/egress-broker/src/index.ts`)**:
  - **`S9-12`..`S9-15`**: Added `sanitizeUrlForAudit()` and `sanitizeAuditText()` before the first audit log entry and SHA-256 hash chain calculation so query secrets (`token`, `password`, `secret`, `code`, `api_key`, etc.), URL userinfo, fragments, and `Authorization`/`Cookie`/`Set-Cookie` values are never logged. Added `BROKER_OUTBOUND_HEADER_ALLOWLIST` (`accept-language`, `x-custom-trace`) to strip arbitrary worker headers (`x-api-key`, `x-forwarded-for`, `host`, etc.), enforced `followRedirects: false` + `redactLocationHeader()`, and added `buildTrustedProxyRequestFromWorkerPayload()` so `/v1/egress/fetch` discards worker-supplied `now`/`env`/`signal` overrides and clamps `timeoutMs`/`maxResponseBytes`.
- **Sprint 8 & Sprint 9 — Honest Prototype Classification & Repository Hygiene (`B3`, `B4`)**:
  - Clarified across [`README.md`](README.md), [`README.tr.md`](README.tr.md), [`PROJECT_STATUS.md`](PROJECT_STATUS.md), and [`docs/ROADMAP.md`](docs/ROADMAP.md) that `apps/api` is a custom zero-dependency PHP 8.4 + SQLite REST API prototype (not the full Laravel framework, PostgreSQL, Redis, or Horizon) and `apps/web` is a custom Node.js `node:http` SSR UI prototype (not Next.js App Router).
  - Archived 15 historical root sprint/audit reports into [`docs/archive/`](docs/archive/) without deleting any files, hardened [`.gitignore`](.gitignore), and added [`scripts/check-markdown-links.ts`](scripts/check-markdown-links.ts) (`npm run docs:links`).
- **Verification**: **84 TypeScript tests** (`79 PASS, 0 FAIL, 5 SKIP` with real Semgrep `1.183.0` + Trivy `0.76.1`; `78 PASS, 0 FAIL, 6 SKIP` inside Windows process sandbox) + **86 PHP API assertions** (`36` module tests + `50` Sprint 9 security regression tests in `npm run test:api`, `86 PASS, 0 FAIL`) = **170 automated checks (`165 PASS, 0 FAIL, 5 honest Docker/Linux SKIPs`)**.

## [0.1.0-alpha.4] — Evidence correctness & Local Workbench hardening (2026-11-04)

- **AUD-06-A**: Per-cookie fingerprint evidence in coverage and re-test (`positive_validation_fingerprints`), preventing a different cookie on the same endpoint from proving a verified fix.
- **AUD-06-B**: Validate `SameSite` values (`Lax`/`Strict`/`None`), reject duplicate `SameSite` attributes, and enforce RFC 6265bis `__Host-` (`Secure`, `Path=/`, no `Domain`) and `__Secure-` (`Secure`) cookie prefix constraints before allowing positive remediation validation.
- **AUD-06-C**: Reject duplicate CSP directives and ambiguous comma-separated policies; refuse positive validation for permissive `script-src-elem` and `script-src-attr` overrides.
- **Local Workbench Hardening (`packages/scanner-core/src/server.ts`)**: Added loopback `Host` (`localhost` / `127.0.0.1` / `[::1]`) and `Origin` / `Sec-Fetch-Site` validation (`validateLoopbackRequest` -> HTTP `403`), bounded `POST` request body reading (`MAX_WORKBENCH_POST_BYTES = 16384` -> HTTP `413`), rejected malformed JSON payloads (`400`), extracted `/workbench.css` and `/workbench.js`, and removed `'unsafe-inline'` from the Workbench `Content-Security-Policy` (`WORKBENCH_CSP_HEADER`).
- **Sprint A / B / C Worker Containment, Signed Execution Grants & Scanner Drift (`apps/worker/`, `integrations/semgrep`, `integrations/trivy`, `packages/recheck-engine`)**:
  - **Sprint A (`G0.5`)**: Added `apps/worker/source-offline-manifest.json` and `buildDockerRunArgsForSourceOffline` enforcing `--user=65532:65532`, `--read-only`, `--cap-drop=ALL`, `--security-opt=no-new-privileges:true`, `--network=none`, `:ro` repository mount, and rejecting `docker.sock`, `.ssh`, secret env vars, and proxy env vars. Added `probeDockerRuntimeAvailability` so `WKR-001`..`WKR-005` runtime container checks report `SKIP (not verified)` (never `PASS`) when Docker Engine is not installed on the host. Added `AbortSignal` (`SIGTERM` -> `SIGKILL`) subprocess cancellation and `tool_status` (`killed`, `timed_out`, `not_installed`, `exited`, `fixture`, `blocked`) tracking.
  - **Sprint B (`G0.6` & Trusted Egress Broker)**: Separated `source-offline` (`--network=none`, where HTTP cannot run) from `remote-web` (external Trusted Egress Broker without worker `CAP_NET_ADMIN`). Added `SignedRemoteExecutionGrant`, `signRemoteExecutionGrant`, `verifySignedRemoteExecutionGrant`, `NonceReplayRegistry`, and `validateCleanProxyEnvironment` enforcing trusted `signer_id`, `TTL <= 300s`, single-use `nonce` replay prevention, target/scope/project binding (grant substitution prevention), and clean proxy environment. Implemented standalone out-of-worker `TrustedEgressBroker` (`apps/egress-broker/src/index.ts`) enforcing deny-by-default (`DROP`) `PerRunNetworkPolicy`, independent broker-side DNS resolution + SSRF/DNS-rebind/redirect blocking, credential header stripping, and SHA-256 hash-chained audit logs (`EGR-001`..`006`). Documented explicitly that HMAC signatures prove control-plane authorization integrity, not kernel/netns enforcement. Kept `restricted-remote` mode strictly `blocked` (`fail-closed`).
  - **Complete `SEC-001..014`, `EGR-001..006` & Sprint 7 Real Security Verification (`scripts/`, `examples/synthetic-targets/`, `.github/workflows/ci.yml`)**:
    - Added `TamperEvidentAuditLog`, `authorizeReportTenantAccess`, extended `redactSensitiveText` (PEM private keys, DB connection URIs, Laravel `APP_KEY`, Next.js `NEXTAUTH_SECRET`), `validateSafeReportOutputPath`, and `EmergencyStopRegistry` integration inside `executeScan`.
    - Added `analyzeDockerRunOutcome` in `apps/worker/src/index.ts` so Docker CLI/daemon errors (`exit 125/126/127`) are never misclassified as container containment passes.
    - Added synthetic security targets for Laravel, Next.js, and Node.js (`examples/synthetic-targets/`) and Trivy misconfiguration (`Misconfigurations`) normalization in `integrations/trivy/src/index.ts`.
    - Completed out-of-process HTTP daemon (`createTrustedEgressBrokerServer` & `handleTrustedEgressBrokerHttpRequest`) and `apps/egress-broker/Dockerfile` for `apps/egress-broker`.
    - Added `scripts/linux-scanner-verify.sh`, `scripts/linux-netns-egress-verify.sh`, and `scripts/release-gate-check.ts` (`npm run verify:release-gate`) alongside 5 separate `ubuntu-24.04` jobs in `.github/workflows/ci.yml`.

## [0.1.0-alpha.3] - 2026-11-04

### Security & Accuracy Fixes (`alpha.2` Independent Audit Remediation)
- **`NEW-01` (P1) — Deep Symlink, Cycle, Unreadable Directory & TOCTOU Fail-Closed (`integrations/semgrep/src/index.ts`, `integrations/trivy/src/index.ts`)**: Removed the fail-open `depth > maxDepth` and `catch { return { safe: true } }` branches in `inspectDirectorySymlinks`. Any directory exceeding `maxDepth`, any symlink cycle (`visitedRealDirs`), or any `readdirSync`/`lstatSync` error now fails closed (`safe: false`, `allowed: false`). Both `runSemgrepAdapter` and `runTrivyAdapter` also re-run `validateAuthorizedRepositoryPath` after execution to catch TOCTOU symlink mutations.
- **`NEW-02` (P1) — Content-Security-Policy Semantic & Permissiveness Validation (`packages/scanner-core/src/index.ts`)**: Added `evaluateCspPolicySemantics` so `evaluateWebHeadersObserver` parses and validates CSP directives rather than treating any non-empty header string as a verified fix. Unrecognized/malformed directives (e.g., `totally-invalid-directive`) emit a `WEB-HEADER-001` (`needs_review`) finding and set `positive_validation_passed: false`; permissive policies (`*`, `'unsafe-inline'`, `'unsafe-eval'`, `data:`) record a caveat note and set `positive_validation_passed: false` so they never become `verified_fixed`. Also hardened `evaluateWebCookiesObserver` so `positive_validation_passed` requires at least one cookie to be observed with all required attributes.
- **`NEW-03` (P1/P2) — Real JSON Schema Draft 2020-12 & Cross-Field Runtime Validator (`packages/findings-schema/src/index.ts`, `schemas/*.schema.json`)**: Replaced partial hand-written checks with a recursive JSON Schema Draft 2020-12 evaluator (`validateAgainstJsonSchema`) loading `schemas/report.schema.json`, `schemas/finding.schema.json`, and `schemas/recheck.schema.json` directly from disk and enforcing `required`, `additionalProperties: false`, `type`, `const`, `enum`, `minimum`, `maximum`, `minLength`, `minItems`, `pattern`, `format: "date-time"`, plus cross-field consistency (`summary.total_findings === findings.length`, `summary.informational_count === informational_notes.length`). Wired validation into `packages/scanner-core/src/cli.ts` prior to report export.
- **Version Sync & Reproducible Lockfile Hygiene**: Synchronized `SCANNER_VERSION = '0.1.0-alpha.3'` dynamically across `package.json`, `packages/findings-schema/src/index.ts`, `packages/scanner-core/src/cli.ts`, and `packages/scanner-core/src/server.ts`, and added `package-lock.json` for reproducible `npm ci` builds.

## [0.1.0-alpha.2] - 2026-11-04

### Security & Accuracy Fixes (Independent Code Audit Remediation)
- **`HS-AUDIT-001` (P0) — Strict Per-Asset Re-Test Matching**: Removed the rule-only fallback (`report.coverage.checks.find((c) => c.rule_id === ruleId)`) for web checks in [`packages/recheck-engine/src/index.ts`](packages/recheck-engine/src/index.ts). Baseline findings on an endpoint (e.g., `/old`) can never be marked `verified_fixed` or `no_longer_observed` when the current scan only evaluated a different endpoint (e.g., `/different-page`); they are now deterministically classified as `not_comparable`.
- **`HS-AUDIT-002` (P0) — Physical `realpathSync` & Symlink Escape Protection**: Hardened [`validateAuthorizedRepositoryPath`](integrations/semgrep/src/index.ts) (used by both Semgrep `CODE-001` and Trivy `DEP-001` adapters) with `realpathSync` and recursive `lstatSync` directory inspection so symlinks or Windows junctions pointing outside `grant.allowed_repositories` are denied before tool execution. Documented explicitly that path validation is a policy gate, not a replacement for container/OS filesystem sandboxing.
- **`HS-AUDIT-003` & `HS-AUDIT-009` (P1/P2) — Explicit Capability Matrix (`Implemented / Mocked / Planned`)**: Clarified across documentation and the local Workbench UI (`OFFLINE FIXTURE G0/G1 PASS · REMOTE DISABLED`) that `v0.1.0-alpha.2` executes web checks against deterministic offline fixtures and local repositories, while live outbound HTTP socket transport (`restricted-remote`) remains intentionally fail-closed until OS/container egress firewall attestation is deployed.
- **`HS-AUDIT-004` (P1) — Grant & Scope Version Comparability Enforcement**: Updated [`compareScanReports`](packages/recheck-engine/src/index.ts) to require matching `grant_id` and `scope_version` between baseline and current runs; any mismatch sets `comparable: false` and marks all items `not_comparable`.
- **`HS-AUDIT-005` (P1) — Real TypeScript Compiler (`tsc --noEmit`) Gate**: Removed unused `RuleId` import in [`packages/policy-engine/src/index.ts`](packages/policy-engine/src/index.ts) and wired `npm run typecheck` to run the real TypeScript compiler (`tsc -p tsconfig.json --noEmit`) alongside runtime schema checks.
- **`HS-AUDIT-006` (P1) — Node.js 22.6+ and Node.js 24 Compatibility**: Added `--experimental-strip-types` to `package.json` scripts and configured a GitHub Actions matrix across Node `22.16.0` and `24.x` in [`.github/workflows/ci.yml`](.github/workflows/ci.yml).
- **`HS-AUDIT-007` (P1) — Repository-Scoped SAST/SCA Re-Test Verification**: Added repository-root matching for `CODE-001` and `DEP-001` in [`packages/recheck-engine/src/index.ts`](packages/recheck-engine/src/index.ts) so scanning a different repository never falsely resolves baseline source/dependency findings.
- **`HS-AUDIT-008` (P2) — Runtime JSON Schema & SARIF 2.1.0 Validators**: Added `validateScanReportDocument`, `validateRecheckReportDocument`, and `validateSarifDocument` in [`packages/findings-schema/src/index.ts`](packages/findings-schema/src/index.ts) and integrated them into `scripts/lint-and-typecheck.ts` and [`tests/security/audit-regression.test.ts`](tests/security/audit-regression.test.ts).
